참가자에게 보낼 링크

참가자는 자기 휴대폰이나 컴퓨터에서 링크를 열고 참가자 ID를 입력한 뒤 과제를 합니다. 로그인은 필요 없습니다.

링크 끝에 &pid=P001을 붙이면 참가자 ID 입력 칸이 사라지고 그 ID로 기록됩니다. 참가자별 링크를 따로 보낼 때 쓰세요.
